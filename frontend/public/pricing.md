# Pricing — VeilPass

VeilPass is currently an MVP and testnet demo.

## Free MVP

- Price: $0/month
- Network: Stellar Testnet
- Wallet: Freighter
- Included: landing page, two-origin demo, developer docs, local SDK package, host verifier boundary, enrollment flow, Soroban gate registry code, and testnet-oriented scripts
- Limits: not a production hosted service; no paid SLA; no mainnet deployment; no managed customer dashboard
- Best for: reviewers, hackathon judges, testnet experimentation, and developers evaluating the privacy boundary

## Production

- Price: not yet published
- Status: not available in this MVP
- Expected requirements before production: production proof backend, operational monitoring, key management, abuse controls, mainnet policy review, and formal security review

## Important privacy note

VeilPass does not claim anonymity. The issuer sees the wallet address during enrollment. The host dApp receives a scoped private app ID and eligibility verdict, not the Stellar wallet address.
